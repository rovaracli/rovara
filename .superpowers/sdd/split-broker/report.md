## How the script keeps it a pure move
Text is copied unchanged (comments with it); `export` is added only where another module needs the declaration (and for same-module types an exported declaration names); imports are rebuilt per module (type-only where only types are read, so no runtime edge is added); source order inside each module is kept. It refuses, writing nothing, on: a `let` shared across modules (chainRunnerDependencies stays with all its users), a load-time constant read across an import cycle (none), anything that stays in broker.ts but a module needs, a missing anchor. Rerun: `already split` exit 0 (marker); `--check` says whether the tree is split; without the marker, a non-empty target folder stops it (`--force` overrides). `--dry-run --root <checkout>` writes nothing. Also patches the tests that read broker.ts as text or list it in a scan (see below).
